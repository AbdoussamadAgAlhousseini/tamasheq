# AKAL Tamasheq

Infrastructure linguistique et d'intelligence artificielle pour la langue tamasheq et les
savoirs touaregs, gouvernée avec et par les communautés.

> **Statut : phase 0 (recherche et cadrage).** Aucun code applicatif, aucun modèle et aucune
> donnée tamasheq dans ce dépôt pour l'instant. Aucune capacité linguistique n'est revendiquée.

## Documents

- [Rapport de phase 0](docs/phase-0-report.md) : état des lieux, jeux de données, modèles candidats, architecture proposée, risques, plan et décisions à valider.
- [Recherche et sources](docs/research-and-sources.md) : sources vérifiées, niveau de vérification et licences.

## Principes

1. Aucune donnée tamasheq inventée ; aucune source inventée.
2. Une licence publique n'est pas une autorisation d'entraînement.
3. Tamasheq ≠ tamazight.
4. Aucune performance annoncée sans méthodologie et résultats reproductibles.
5. Gouvernance des données selon les principes CARE : les communautés décident.
